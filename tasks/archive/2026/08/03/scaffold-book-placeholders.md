# Scaffold the book's placeholder documents (.rst chapters + notebook stubs)

**Created:** 2026-08-02 · **Completed:** 2026-08-02

## What was done

Scaffolded the empty skeleton of the book per `tasks/reference/book-outline.md`, after the
maintainer reviewed the outline and green-lit it:

- **19 prose pages** `book/docs/<name>.rst` (one per outline section) + `proof-rotate.rst` (hidden
  proof page), reading order in `book/docs/index.rst`.
- **14 companion notebooks** `book/docs/notebooks/<name>.py` (percent format), for the sections
  whose payoff is running gacalc, each a single `1 + 1` cell to prove execution. Which sections
  have notebooks: `book-outline.md` › "File layout".
- **Build wiring:** `entrypoint/docs.sh` converts the percent notebooks to `.ipynb` (jupytext)
  before the Sphinx build so myst_nb executes them; `.gitignore` ignores the generated
  `book/docs/notebooks/*.ipynb`.

The pages and notebooks were generated by a one-shot, data-driven scaffold script,
`create-placeholders.sh` (removed at archive; in git history). The build-file edits (`docs.sh`,
`.gitignore`) were made directly.

## Verification (sandbox)

- Full HTML build succeeded: 25 pages.
- All 14/14 notebooks executed; the `1 + 1` result rendered on each notebook page.
- The 12 build warnings were the pre-existing autodoc `|A|` docstring issue, unrelated (tracked
  in `tasks/reference/book-and-docs-pipeline.md`).
