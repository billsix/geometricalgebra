## What was done

Scaffolded the empty skeleton of the book per `tasks/reference/book-outline.md`, after
Bill reviewed the outline and green-lit it:

- **19 prose pages** `book/docs/<name>.rst` (one per outline section) + `proof-rotate.rst`
  (hidden proof page), reading order in `book/docs/index.rst`.
- **14 companion notebooks** `book/docs/notebooks/<name>.py` (percent format), for the
  sections whose payoff is running gacalc — each currently a single `1 + 1` cell to prove
  execution. Which sections have notebooks: see `book-outline.md` › "File layout".
- **Build wiring:** `entrypoint/docs.sh` now converts the percent notebooks to `.ipynb`
  (jupytext) before the Sphinx build so myst_nb executes them; `.gitignore` ignores the
  generated `book/docs/notebooks/*.ipynb`.

## Verified (sandbox)

- Full HTML build succeeds — 25 pages.
- All **14/14** notebooks execute; the `1 + 1` result renders on each notebook page.
- (12 build warnings are the pre-existing autodoc `|A|` docstring issue, unrelated —
  tracked in `book-and-docs-pipeline.md`.)

## How it was built

Generated by the one-shot scaffold script
`tasks/adhoc/scaffold-book-placeholders/create-placeholders.sh` (heavily commented,
data-driven over the ordered page list). It is one-shot: **removed at archive** (its
output — the `.rst`/`.py` files — is what's kept). The build-file edits (`docs.sh`,
`.gitignore`) were made directly, not scripted.
